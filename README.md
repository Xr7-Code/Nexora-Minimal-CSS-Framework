# Nexora Minimal CSS Framework

Ein leichtgewichtiges, minimal-first CSS-Framework für moderne Firmen- und
Landingpage-Websites. Kein Build-Step, keine Abhängigkeiten, ~12 KB (unkomprimiert).

**Features:**

- 🎨 Light-first Design mit automatischem Dark Mode (`prefers-color-scheme`)
- 📐 Design-Tokens (Farben, Spacing, Typografie, Radien, Schatten)
- 🧩 Fertige Komponenten: Navbar, Hero, Cards, Grid, Forms, FAQ, Stats, CTA, Footer
- 📱 Responsive ohne Media-Query-Chaos (`auto-fit` / `minmax`)
- ♿ Barrierefreiheit: Skip-Link, Fokus-Ringe, `prefers-reduced-motion`, `sr-only`
- ⚡ Null Abhängigkeiten — funktioniert mit reinem HTML

**Demo:** https://xr7-code.github.io/Nexora-Minimal-CSS-Framework/
